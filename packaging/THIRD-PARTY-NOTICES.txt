qtv8reader использует компоненты третьих сторон.

Qt 6 (Qt Core, Gui, Widgets, Concurrent, Network, Svg)
  Copyright (C) The Qt Company Ltd.
  Лицензия: GNU Lesser General Public License v3 (LGPL-3.0).
  Динамическая компоновка: библиотеки Qt поставляются отдельными файлами,
  пользователь может заменить их собственными сборками совместимой версии.
  Исходный код Qt: https://download.qt.io/ и https://code.qt.io/
  Условия лицензирования: https://www.qt.io/licensing/

Иконки дерева метаданных (resources/icons/metadata)
  Набор metadata-icons из проекта vscode-1c-metadata-viewer
  (https://github.com/zerobig/vscode-1c-metadata-viewer), лицензия MIT.
  Иконки перекрашены в палитру, близкую к 1С:Предприятие, и отрендерены
  в PNG. Текст лицензии: resources/icons/metadata/LICENSE-METADATA-ICONS.txt
zlib
  Copyright (C) Jean-loup Gailly and Mark Adler
  Лицензия: zlib License.

ICU (International Components for Unicode)
  Copyright (C) Unicode, Inc.
  Лицензия: Unicode License.

MinGW-w64 runtime (libgcc, libstdc++, libwinpthread)
  Copyright (C) Free Software Foundation, Inc.
  Распространяется под GNU GPL с исключением для runtime-библиотек.

libpng, FreeType, HarfBuzz, GLib, PCRE2, Brotli, zstd, bzip2, xz, libgcrypt,
libxcb, libxkbcommon и другие библиотеки
  Распространяются под соответствующими открытыми лицензиями; полные тексты
  лицензий находятся в пакетах соответствующих библиотек и в их исходных
  репозиториях.

Microsoft Edge WebView2 SDK (3rdparty/webview2)
  Copyright (C) Microsoft Corporation.
  В поставку входят заголовок WebView2.h и WebView2Loader.dll; условия —
  файлы 3rdparty/webview2/LICENSE.txt и 3rdparty/webview2/NOTICE.txt.
  Сам браузерный рантайм Microsoft Edge WebView2 Runtime в поставку НЕ
  входит: он устанавливается отдельно и входит в Windows 10/11; при его
  отсутствии приложение работает без режима «точный вид».

Рендерер управляемых форм BslEdit (packages/1c-preview-core)
  https://github.com/alonehobo/BslEdit
  Copyright (C) BslEdit contributors.
  Лицензия: MIT. В поставку входят статические ресурсы рендерера
  (resources/formpreview: form-preview.js, css, картинки) для режима
  «точный вид». Текст лицензии — resources/formpreview/LICENSE-BslEdit-MIT.txt.
