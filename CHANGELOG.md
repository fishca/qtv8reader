# История изменений

## [0.3.0] — 2026-11-16

### Добавлено

- Иерархическое дерево метаданных в стиле конфигуратора 1С: стандартные ветки,
  объекты, модули и разделы состава. При открытии дерево свёрнуто, как в 1С.
- Иерархия подсистем: вложенные подсистемы из состава родительской подсистемы.
- Иконки типов объектов и разделов в стиле 1С (набор metadata-icons, MIT,
  перекрашен и отрендерен в PNG 16/24/32).
- Порядок ветки «Общие» по руководству разработчика 1С 8.3; «Планы обмена»
  внутри «Общие», «Нумераторы»/«Последовательности» первыми в «Документы».
- Пустые стандартные ветки показываются, как в 1С; клик по пустой ветке
  показывает сводку категории.
- Поиск по дереву, свойства узла, вкладки «Состав», «Модуль», «Метаданные»,
  «Контейнер».
- Режимы `--smoke` и `--screenshot`, ключи `--expand-common` и
  `--expand-documents`.
- README со скриншотами и документация по форматам 1С.

### Исправлено

- Описатели объектов 1.5/1.6 и «конфигурация из одного объекта»
  (`.epf/.erf`), чтение `configinfo` расширений.
- Модули: отбрасывание HTML-справок, выбор основного модуля формы.
- Ленивый разбор состава объектов, распараллеливание построения модели.

## [0.2.0] — 2026-11-15

- Первый публичный релиз: чтение `.cf/.cfe/.epf/.erf`, CLI и GUI,
  выгрузка объектов, портативные сборки Windows и Linux (AppImage, tar.gz),
  GitHub Actions.
