# qtv8reader v0.6.1

**18 ноября 2026**

Версия 0.6.1 — производительность и внутренний рефакторинг без изменения
форматов файлов и пользовательского поведения.

## Главное

- Ускорена загрузка больших конфигураций, в том числе БП 3.0
  (15 523 объекта, файл ~762 МБ).
- Поиск элементов контейнера переведён с линейного перебора на хеш-индекс.
- Вкладка «Контейнер» в GUI заполняется лениво — только при первом переходе.
- `ConfigurationReader` и `MainWindow` разделены на небольшие подсистемы;
  CLI вынесен в отдельную библиотеку.

## Замеры

Замеры на `1Cv8_bp.cf` (БП 3.0, 15 523 объекта):

| Сценарий | До | После |
|---|---:|---:|
| `v8reader_cli info` | ~2,2 с | **~0,9 с** |
| Открытие GUI | ~2,9 с | **~1,3 с** |
| `qtv8reader_tests` | ~8,2 с | **~3,7 с** |

## Изменения

### Производительность

- `V8Container::find()`/`indexOf()` используют хеш-индекс по имени
  без учёта регистра. Устранён квадратичный поиск при построении
  метаданных больших конфигураций.
- Дерево вкладки «Контейнер» строится при первом открытии вкладки,
  а не при загрузке файла; перед контекстным меню и двойным кликом
  дерево создаётся автоматически.
- Создание элементов дерева контейнера идёт с отключёнными обновлениями
  виджета.

### Рефакторинг

- `ConfigurationReader` разделён на `MetadataTextUtils`, `TypeResolver`,
  `SubscriptionParser` и `SectionBuilder`; публичный API сохранён.
- Общие эвристики текста и форматирования вынесены в `BinaryText` и
  `DisplayText`; для выгрузки сохранено распознавание UTF-16.
- CLI: `CliApplication` + `Output`, тонкий `main.cpp`.
- GUI: `qtv8reader_gui`, `ThemeController`, `ModulePanel`, `PropertiesPanel`,
  `MetadataIcons`; `MainWindow` разделён по подсистемам.
- Добавлены тесты CLI и GUI-панелей.

## Совместимость

- Поддерживаемые файлы: `.cf`, `.cfe`, `.epf`, `.erf`, `.cfu`;
  контейнеры 1.5 и 1.6.
- Форматы файлов и публичный API не менялись.
- Настройки, горячие клавиши и параметры автоматизации GUI сохранены.

## Файлы релиза

- **Windows x64** — `qtv8reader-*-windows-x86_64.zip` — портативная сборка:
  Qt и библиотеки внутри, установка не требуется. Требуется Windows 10/11 x64.
  Запуск: распаковать и открыть `qtv8reader.exe`.
- **Linux x64 AppImage** — `qtv8reader-*-linux-x86_64.AppImage` — один
  самодостаточный файл. Требуется glibc 2.35+ (Ubuntu 22.04+, Debian 12+,
  Fedora 36+). Запуск: `chmod +x qtv8reader-*.AppImage && ./qtv8reader-*.AppImage`.
- **Linux x64 tar.gz** — `qtv8reader-*-linux-x86_64.tar.gz` — бинарники
  с библиотеками, включая `bin/v8reader_cli`.
- `SHA256SUMS` — контрольные суммы.

## Проверки
