# qtv8reader 0.4.0

Релиз с поддержкой табличных документов 1С (MXL): собственный парсер,
просмотр макетов, именованные области, параметры печати, печать и экспорт в PDF.

## Что нового

### Чтение и просмотр MXL

- Собственный парсер **MXL8** (1С 8.2/8.3/BAS): заголовок `MOXCEL`,
  строки и ячейки, форматы, шрифты, цвета, линии, объединения, группы
  колонок, именованные области, параметры печати, рисунки и картинки
  (базово).
- Вкладка **«Табличный документ»** в GUI: макет открывается из дерева
  (раздел «Макеты»), отображается с сохранением раскладки, шрифтов, рамок
  и объединений; есть сетка ячеек как в конфигураторе и масштабирование
  (`Ctrl + колесо`).
- **Именованные области** (`Титул`, `Шапка`, `Строка`, `Подвал`, …)
  подсвечиваются на макете, их список виден в свойствах.
- **Параметры печати** из макета: размер страницы, ориентация, масштаб,
  поля, колонтитулы.

### Печать и PDF

- **«Объект → Печать макета…»** — печать через системный диалог.
- **«Объект → Экспорт макета в PDF…»** — PDF с учётом параметров печати
  макета и разбиением на страницы по колонкам и строкам.
- Шрифты в PDF векторные; проверено на A4/A3, книжной и альбомной
  ориентации.

### CLI

- Новая команда `mxl`:
  - сводка по макетам объекта: строки/колонки, форматы, шрифты,
    объединения, именованные области, параметры печати;
  - для standalone `.mxl` — разбор файла;
  - `-o <каталог>` — сохранение макетов;
  - `--select-mxl <объект>` — открыть приложение сразу на нужном макете;
  - `--mxl-pdf`, `--mxl-object`, `--show-areas` — экспорт PDF и подсветка
    областей для автоматизации.

### Прочее

- Рендеринг приближен к 1С: ширины колонок по стандартному символу,
  автовысота строк с учётом переноса, переполнение текста в пустые соседние
  ячейки, обработка дополнительного поля маркера ячейки (подписи-параметры
  вида `РуководительПредставление`).
- Добавлена зависимость **Qt6 PrintSupport** (входит в стандартную Qt).

## Поддерживаемые форматы

- `.cf` — конфигурация;
- `.cfe` — расширение конфигурации;
- `.epf` / `.erf` — внешняя обработка / отчёт;
- `.cfu` — сжатый целиком файл;
- контейнеры 1С:V8 1.5 и 1.6;
- `.mxl` и макеты внутри контейнеров — формат MXL8.

## Готовые сборки

### Windows 10/11 x64

`qtv8reader-0.4.0-windows-x86_64.zip` — портативная сборка: Qt и все
библиотеки внутри, установка не нужна. Распаковать и запустить
`qtv8reader.exe` (рядом — `v8reader_cli.exe`).

### Linux x64

- `qtv8reader-0.4.0-linux-x86_64.AppImage` — один самодостаточный файл:

  ```sh
  chmod +x qtv8reader-0.4.0-linux-x86_64.AppImage
  ./qtv8reader-0.4.0-linux-x86_64.AppImage
  ```

  Требуется glibc 2.35+ (Ubuntu 22.04+, Debian 12+, Fedora 36+).

- `qtv8reader-0.4.0-linux-x86_64.tar.gz` — бинарники с библиотеками,
  включая консольную утилиту `bin/v8reader_cli`.

Контрольные суммы — в файле `SHA256SUMS`.

## Проверено

- 53 автотеста (контейнеры 1.5/1.6, текст 1С, модель конфигурации, состав,
  модули, выгрузка, MXL: строки/форматы/объединения/области/параметры печати).
- Реальные файлы: БП 3.0 `.cf` (15 523 объекта), внешняя обработка `.epf`,
  расширение `.cfe`; макет «АвансовыйОтчет» (74×25, 217 объединений,
  4 именованные области).
- PDF: A4 книжная/альбомная, A3 книжная; страницы и MediaBox проверены.
- CI: Windows (MSYS2/UCRT64) и Linux (Ubuntu 24.04/u 22.04).

## Ограничения

- Просмотр MXL — read-only; редактирование не поддерживается.
- Узоры заливки, картинки и графические объекты поддерживаются частично.
- Колонтитулы и принудительные разрывы страниц из макета пока не
  учитываются — пагинация автоматическая.
- Нативная печать зависит от наличия в сборке Qt плагина поддержки
  принтера; экспорт в PDF работает всегда.
- Формат MXL 7.7 (бинарный) не поддерживается.
