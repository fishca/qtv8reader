# qtv8reader 0.6.0

Релиз про детали метаданных: типы реквизитов, модули команд и корня
конфигурации, свойства подписок на события, а также подсветка модулей
и светлая/тёмная темы.

## Что нового

### Типы реквизитов и объектов

- Тип значения реквизита, измерения и ресурса: «Строка(50)», «Число(15,2)»,
  «Булево», «Дата», «СправочникСсылка.Валюты», «ПеречислениеСсылка.…»,
  «ПланСчетовСсылка.…», определяемый тип, составной тип.
- Собственный тип значения у объектов «Общие реквизиты», «Константы»,
  «Параметры сеанса».
- Тип показывается в свойствах узла (строка «Тип»), в подсказке дерева,
  в колонке «Вид» вкладки «Состав» («Реквизит · Строка(50)»), в
  `v8reader_cli composition` и в `composition.txt`.

### Команды и корневые модули

- «Модуль команды»: у объектов «Общие команды» модуль читается из
  `<GUID>.0…5` и больше не подписывается «Модуль объекта»; у команд объекта —
  «Модуль команды «Имя»». Узел получил иконку команды.
- Корневые модули конфигурации у корня дерева: **Модуль приложения**,
  **Модуль сеанса**, **Модуль внешнего соединения** (и «Модуль обычного
  приложения»): текст открывается на вкладке «Модуль».
- `v8reader_cli modules <файл>` без объекта выводит корневые модули.

### Подписки на события

- В свойствах подписки: **Источник** (`ДокументСсылка.…`, для составного —
  список), **Событие** (`ОбработкаПроведения`, `ПередЗаписью`, …),
  **Обработчик** (`ОбщийМодуль.Процедура`).
- То же выводит `v8reader_cli composition`; строка «Событие» добавлена
  в подсказку дерева.

### Подсветка модулей и темы

- Синтаксическая подсветка текстов модулей 1С: ключевые слова, строки,
  комментарии, числа, директивы препроцессора, аннотации. Включается
  в меню «Вид → Подсветка модулей» и запоминается.
- Светлая и тёмная темы интерфейса («Вид → Тема»); выбор сохраняется,
  подсветка модулей перекрашивается под тему.
- «О программе» показывает реальный номер версии сборки и версию Qt.

## Проверено

- 63 автотеста (16 V8Text + 12 контейнеров + 21 метаданных + 8 MXL + 6 форм),
  включая реальные файлы БП.
- CLI и GUI на `1Cv8_bp.cf` (15 523 объекта): типы, команды, корневые модули,
  подписки на события, подсветка, темы.
- CI: Windows (MSYS2/UCRT64) и Linux (GCC).

## Готовые сборки

### Windows 10/11 x64

`qtv8reader-v0.6.0-windows-x86_64.zip` — портативная сборка, Qt и все
библиотеки внутри. Распаковать и запустить `qtv8reader.exe`.

### Linux x64

- `qtv8reader-v0.6.0-linux-x86_64.AppImage` — самодостаточный файл
  (glibc 2.35+):

  ```sh
  chmod +x qtv8reader-v0.6.0-linux-x86_64.AppImage
  ./qtv8reader-v0.6.0-linux-x86_64.AppImage
  ```

- `qtv8reader-v0.6.0-linux-x86_64.tar.gz` — бинарники с библиотеками,
  включая `bin/v8reader_cli`.

Контрольные суммы — в `SHA256SUMS`.

## Ограничения

- Проект работает только на чтение; исполнение модулей и форм
  не поддерживается.
- Просмотр форм — управляемые формы (8.2/8.3/BAS); обычные формы 8.1/8.2
  не поддерживаются.
- Для экзотических версий платформы возможны расхождения в составе объектов;
  для них предусмотрен резервный поиск таблиц по GUID.
