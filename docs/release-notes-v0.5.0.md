# qtv8reader 0.5.0

Релиз с поддержкой **управляемых форм 1С**: просмотр структуры формы,
раскладка, приближенная к 1С, иконки команд и чтение геометрии элементов.

## Что нового

### Чтение и просмотр форм

- Собственный парсер управляемых форм 1С из `.cf/.cfe`: элементы формы
  (группы, поля, кнопки, таблицы, декорации), вложенность, атрибуты формы,
  команды и модуль.
- Новая вкладка **«Форма»**: дерево элементов (с типами, именами, синонимами
  и подсказками по геометрии) и макет формы.
- Форма открывается при выборе в дереве метаданных; свойства показывают число
  элементов, полей, атрибутов, команд и размер модуля.
- Масштаб макета 50–150%; запуск сразу на форме:
  `qtv8reader.exe "C:\1c\bp.cf" --select-form "АвансовыйОтчет:ФормаСписка"`.

### Раскладка, приближенная к 1С

- Вертикальные и горизонтальные группы, вложенность, выравнивание подписей
  полей, страницы с вкладками, таблицы, командные панели, подменю.
- Быстрые отборы: чекбокс + подпись реквизита + поле со стрелкой.
- Таблица формы списка занимает основную высоту формы; горизонтальная
  прокрутка и ширины колонок по содержимому/Width.
- Масштаб 50–150% и фиксированная логическая ширина формы.

### Геометрия из бинарного формата (сверено с XML-выгрузкой)

- **Width / Height / HorizontalStretch / VerticalStretch** полей, групп
  и декораций; ширины колонок таблицы.
- **Visible** и **TitleLocation** полей: скрытые поля не рисуются,
  поля без заголовка выводятся без подписи.
- Сопоставление проверено по 11 формам «Авансового отчёта» (XML ↔ бинарь):
  `Дата` Width 7, `СуммаДокумента` Width 10, `ТекстБаннера` Height 3,
  группы с фиксированным растяжением и т. д.

### Командные панели и иконки

- Векторные иконки для стандартных команд: «Создать», «Создать на основании»,
  «Скопировать», «Изменить», «Печать», «Показать движения», «Присоединённые
  файлы», «История изменений», «Заполнить», «Отчёты», «ЭДО», «Справка» и др.
- Длинные команды показываются компактными icon-only кнопками, подменю —
  с выпадающим меню.
- Для формы списка документа синтетически добавляются runtime-команды
  «Создать на основании», «Еще» и «?», как в 1С.

### Прочее

- Флаг `--form-scale` для автоматизации скриншотов формы.
- Тесты: **59** (16 V8Text + 12 контейнеров + 17 метаданных + 8 MXL +
  6 форм), включая реальные формы БП (список и документ).
- Документация: `docs/research/forms-format.md` (структура формы, коды
  элементов, сопоставление XML ↔ бинарь), README, скриншоты.
- CI: Windows (MSYS2/UCRT64) и Linux.

## Поддерживаемые форматы

`.cf`, `.cfe`, `.epf`, `.erf`, `.cfu`; контейнеры 1С:V8 1.5/1.6; макеты MXL8;
управляемые формы 8.2/8.3/BAS из этих контейнеров.

## Готовые сборки

### Windows 10/11 x64

`qtv8reader-0.5.0-windows-x86_64.zip` — портативная сборка, Qt и все
библиотеки внутри. Распаковать и запустить `qtv8reader.exe`.

### Linux x64

- `qtv8reader-0.5.0-linux-x86_64.AppImage` — самодостаточный файл
  (glibc 2.35+):

  ```sh
  chmod +x qtv8reader-0.5.0-linux-x86_64.AppImage
  ./qtv8reader-0.5.0-linux-x86_64.AppImage
  ```

- `qtv8reader-0.5.0-linux-x86_64.tar.gz` — бинарники с библиотеками,
  включая `bin/v8reader_cli`.

Контрольные суммы — в `SHA256SUMS`.

## Проверено

- 59 автотестов; реальные файлы БП: конфигурация (15 523 объекта), внешняя
  обработка, расширение; макет «АвансовыйОтчет»; формы «ФормаДокумента»
  и «ФормаСписка».
- Геометрия/видимость сверены с XML-выгрузкой конфигурации БП (11 форм).
- CI: Windows + Linux.

## Ограничения

- Просмотр форм — read-only; обычные (неуправляемые) формы 8.1/8.2
  не поддерживаются.
- `Visible` групп и декораций пока не расшифрован (баннер и его подгруппы
  скрываются по имени); некоторые свойства групп/таблиц не читаются.
- Runtime-команды («Создать на основании», «Еще», «?») и чипы отборов
  отображаются приближенно: чипы — это пользовательские настройки,
  а не элементы формы.
- MXL: узоры заливки/картинки — частично; колонтитулы и принудительные
  разрывы страниц не учитываются.
