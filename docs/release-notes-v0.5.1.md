# qtv8reader 0.5.1

Патч-релиз про дерево метаданных: разделы состава объекта идут в порядке
конфигуратора 1С, пустые разделы показываются пустыми контейнерами, а у
«Критериев отбора» и «Хранилищ настроек» — правильный состав.

## Что нового

### Порядок разделов состава как в 1С

Разделы объекта теперь идут в порядке конфигуратора, а не в порядке таблиц
контейнера:

- справочники, документы, отчёты, обработки, планы: **Реквизиты →
  Табличные части → Формы → Команды → Макеты**;
- регистры: **Измерения → Ресурсы → Реквизиты → … → Формы → Команды → Макеты**;
- регистры бухгалтерии: **… → Признаки учёта → Признаки учёта субконто → …**;
- журналы документов: **Графы → Табличные части → …**; перечисления:
  **Значения → Формы → Команды → Макеты**.

Порядок одинаков в GUI и в CLI (`v8reader_cli composition`).

### Пустые разделы

- Разделы состава показываются всегда: если элементов нет, остаётся пустой
  родительский контейнер без раскрывателя — как в конфигураторе 1С.
- Счётчик «(N)» выводится только у непустых разделов; у пустых — просто
  название. Подсказка пустого раздела: «Раздел пуст».

### Критерии отбора и хранилища настроек

- «Критерии отбора»: разделы **«Формы» и «Команды»** (формы читаются по
  таблице `00867c40-06b1-11d6-a3c7-0050bae0a776`, команды — по
  `23fa3b84-220a-40e9-8331-e588bed87f7d`).
- «Хранилища настроек»: разделы **«Формы» и «Макеты»**; формы читаются по
  таблице `b8533c0c-2342-4db3-91a2-c2b08cbf6b23` — в БП, например, 13 форм
  у «ХранилищеВариантовОтчетов», 4 у «НастройкиНовостей», 1 у
  «БуферыОбменаНовостей».
- Найденные GUID таблиц и состав объектов описаны в
  `docs/research/metadata-sections.md`.

## Проверено

- 59 автотестов (16 V8Text + 12 контейнеров + 17 метаданных + 8 MXL + 6 форм),
  включая реальные файлы БП.
- CLI и GUI на `1Cv8_bp.cf` (15 523 объекта): справочники, документы,
  регистры, критерии отбора, хранилища настроек.
- CI: Windows (MSYS2/UCRT64) и Linux (GCC).

## Готовые сборки

### Windows 10/11 x64

`qtv8reader-v0.5.1-windows-x86_64.zip` — портативная сборка, Qt и все
библиотеки внутри. Распаковать и запустить `qtv8reader.exe`.

### Linux x64

- `qtv8reader-v0.5.1-linux-x86_64.AppImage` — самодостаточный файл
  (glibc 2.35+):

  ```sh
  chmod +x qtv8reader-v0.5.1-linux-x86_64.AppImage
  ./qtv8reader-v0.5.1-linux-x86_64.AppImage
  ```

- `qtv8reader-v0.5.1-linux-x86_64.tar.gz` — бинарники с библиотеками,
  включая `bin/v8reader_cli`.

Контрольные суммы — в `SHA256SUMS`.

## Ограничения

- Проект работает только на чтение; исполнение модулей и форм
  не поддерживается.
- Просмотр форм — управляемые формы (8.2/8.3/BAS); обычные формы 8.1/8.2
  не поддерживаются.
- MXL: узоры заливки и картинки — частично; колонтитулы и принудительные
  разрывы страниц из макета не учитываются.
- Для экзотических версий платформы возможны расхождения в составе объектов;
  для них предусмотрен резервный поиск таблиц по GUID.
