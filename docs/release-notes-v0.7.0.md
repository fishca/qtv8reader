# qtv8reader v0.7.0

**21 ноября 2026**

Главное в 0.7.0 — **«точный вид» управляемых форм**: форма рисуется тем же
HTML/CSS-рендерером, что и в конфигураторе 1С, внутри Microsoft Edge WebView2,
а данные берутся напрямую из контейнера 1С. Плюс упрощённый рендерер доведён
до эталона конфигуратора по геометрии, шрифтам и цветам, и проект официально
перешёл на лицензию MIT.

## Главное

- **Точный вид формы** — второй режим просмотра: браузерный рендерер
  конфигуратора 1С (проект BslEdit, MIT) внутри Microsoft Edge WebView2.
  Включается в меню «Вид → Точный вид форм (как в конфигураторе)» или
  переключателем «Вид: Упрощённый / Точный» прямо в просмотре формы; выбор
  запоминается.
- **Данные — из контейнера, а не из XML.** Разобранная форма сериализуется
  в JSON-модель, которую приложение отдаёт странице по внутреннему
  виртуальному хосту `https://qv8.local/`. Ни выгрузки XML, ни временных
  файлов, ни обращений к сети.
- **Упрощённый рендерер доведён до эталона**: Tahoma 9 pt, шапка таблицы
  31 px, раскладка, отступы и уголок прокрутки по размерам конфигуратора —
  средняя попиксельная разница с эталонным скриншотом формы списка
  уменьшилась до 7,24 (по шкале 0–255).
- **Без WebView2 приложение работает как раньше**: точный вид просто
  недоступен, в форме выводится пояснение.

## Точный вид формы

### Как включить

- меню **«Вид → Точный вид форм (как в конфигураторе)»** — режим действует
  для всех форм, выбор сохраняется в настройках (`MainWindow/exactFormView`);
- переключатель **«Вид: Упрощённый / Точный (как в 1С)»** в самом просмотре
  формы — то же самое, но на виду;
- ключ командной строки `--exact-form-view` — разово открыть форму в точном
  виде, не меняя сохранённую настройку.

Масштаб 50–150 % передаётся странице, поэтому форма увеличивается так же,
как в конфигураторе. Отладочный журнал WebView2 пишется в файл, если задана
переменная окружения `QTV8_WEBVIEW2_LOG=<файл>`.

### Что нужно

Windows и установленный
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
(Evergreen; обычно уже есть в Windows 10/11 вместе с Edge). `WebView2Loader.dll`
из комплекта SDK теперь лежит в архиве рядом с `qtv8reader.exe`; SDK-библиотека
не линкуется — загрузчик подгружается динамически, и при его отсутствии или
без рантайма приложение продолжает работать.

### Как устроено

- Модель формы (`src/core/FormWebModel.*`) строится из того же разбора
  скобочного формата контейнера, что и обычный просмотр, и сериализуется в
  JSON в терминах XCF: элементы (`UsualGroup`, `Pages`/`Page`, `InputField`,
  `LabelField`, `CheckBoxField`, `Table` с колонками, `Button`, `Popup`,
  `LabelDecoration`), свойства (`Title`, `DataPath`, `Width`, `Group`,
  `Representation`, `Behavior`, `TitleLocation`, `HorizontalStretch`),
  командная панель со стандартными командами платформы, реквизиты и команды
  формы, метаданные владельца (`objectMeta`).
- Виджет `WebView2Host` (`src/gui/web/`) перехватывает все запросы
  виртуального хоста: ресурсы рендерера отдаются из qrc, модель формы —
  из памяти.
- Ресурсы рендерера (HTML, CSS, JS, картинки — 426 файлов, 2,3 МБ) входят
  в исполняемый файл через qrc. Рендерер BslEdit распространяется по MIT,
  текст лицензии — `resources/formpreview/LICENSE-BslEdit-MIT.txt`.

Подробности — в [docs/form-exact-view.md](docs/form-exact-view.md), контракт
модели и разбор «что влияет на пиксели» — в
[docs/research/exact-form-model.md](docs/research/exact-form-model.md).

## Упрощённый вид

Второй режим остался по умолчанию и заметно приближен к конфигуратору:

- Собственная библиотека контролов (`src/gui/controls/`): `FormStyle`,
  `FormControl`, `ButtonControl`, `FieldControl`, `TableControl`,
  `TabControl`, `ScrollBarControl`, `StaticControl`, `CommandBarControl`.
  Golden-скриншоты формы списка и документа при выделении контролов
  совпадали побайтово.
- Положение подписи поля (`TitleLocation`) сохраняется полностью
  (`None`/`Auto`/`Left`/`Top`/`Right`/`Bottom`); группы читают из макета
  выделение (`Representation`) и поведение (`Behavior`) — секции, раскрываемые
  и всплывающие группы рисуются по-разному, как в 1С.
- Типы реквизитов из метаданных: булево — флажком, дата — с календарём,
  ссылка — с кнопкой выбора; заголовки и ширины колонок — по составу объекта.
- Командная панель переносит кнопки на вторую строку и не наезжает на поля;
  на масштабах 125–150 % второстепенные команды сворачиваются.
- Шрифт Tahoma 9 pt, цвета, рамки и сетка таблицы сняты с эталона.

## CLI и автоматизация

- `v8reader_cli form-model <файл> <объект> [--form <имя>] [-o <файл>]` —
  JSON-модель формы для рендерера; `--items` печатает дерево элементов формы
  с кодами типов, видами групп и разобранными свойствами.
- В GUI: `--select-form <объект>[:<форма>]`, `--exact-form-view`,
  `--form-scale <проценты>`, `--screenshot <файл>`.

рендерер.

## Ограничения

- Проект работает только на чтение; исполнение модулей и форм
  не поддерживается.
- Просмотр форм — управляемые формы (8.2/8.3/BAS); обычные формы 8.1/8.2
  не поддерживаются.
- В точном виде пока не перенесены из формы некоторые данные, которые
  конфигуратор подставляет сам: цвета стилей (`styleItems` — жёлтый баннер,
  серые итоги), картинки и представление общих команд (`commonCommands`),
  вычисляемые ширины полей (`runtime`) и подвал таблицы. Расхождения
  локальные; что нужно для каждого пункта — в
  [docs/research/exact-form-model.md](docs/research/exact-form-model.md).
- Для экзотических версий платформы возможны расхождения в составе объектов;
  для них предусмотрен резервный поиск таблиц по GUID.
