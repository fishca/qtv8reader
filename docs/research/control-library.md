# Библиотека 1С-контролов

Направление: не рисовать форму одним большим `paintControl`, а собирать её
из переиспользуемых контролов с общим стилем. Это внутренняя библиотека
отрисовки, а не визуальный конструктор: поведение формы пока остаётся
режимом просмотра.

## Что уже есть

- `src/gui/controls/FormStyle.h` — палитра и метрики 1С 8.3 («Такси»).
- `src/gui/controls/FormControl.h` — базовый контрол: геометрия, `hitTest`,
  виртуальный `paint`.
- `src/gui/controls/SearchControl.h/.cpp` — строка поиска и кнопка поиска
  с выпадающим списком.
- `src/gui/controls/ButtonControl.h/.cpp` — кнопки и их иконки: плоские,
  с рамкой, кнопка по умолчанию, выпадающий список.

`FormView.cpp` использует эти контролы для отрисовки поиска и кнопок;
остальные элементы пока рисуются прежним кодом.

## Правило переноса

Один контрол за шаг. После переноса golden-скриншот формы должен совпасть
с прежним побайтово (при том же размере окна и масштабе). Если хеш
изменился — сначала выясняется, это ожидаемое изменение стиля или ошибка
переноса.

## План

1. `ButtonControl` — сделано: плоские кнопки, кнопка по умолчанию,
   рамка, иконки.
2. `FieldControl` — подпись, поле ввода, флажок, кнопки выбора/календаря.
3. `TableControl` — шапка, строки, сетка, колонки, скроллбары.
4. `CommandBarControl` — раскладка команд, «Еще», поиск, «?».
5. `TabBarControl`, `ScrollBarControl`, `GroupControl`.
6. `FormSurface` — собирает дерево контролов, рисует и обрабатывает
   hover/focus; `LayoutEngine` продолжает вычислять координаты.

Интерактивность (ввод, клики, события) в этот этап не входит; базовый
`FormControl` уже содержит `hitTest`, чтобы добавить её позже без смены
модели.
